# Data Directory

Large lunar orbiter images (OHRC, TMC-2) are stored outside this repository:
- `D:\ChandraData\triplet_1\OHRC\data\calibrated\20210405\`
- `D:\ChandraData\triplet_1\TMC\data\calibrated\20250807\`

Do NOT place raw images or multi-gigabyte files in this repository.
Use configuration (`configs/default.yaml`) to reference external datasets.
